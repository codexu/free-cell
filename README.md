FreeCell 是一款使用 React、PixiJS 和 Tauri 开发的空当接龙游戏，优先适配手机，也可在浏览器和桌面端运行。无需登录，牌局、成绩和设置保存在当前设备。

## 经典空当接龙怎么玩

牌桌由 **八列牌、四个中转格、四个收牌区** 组成。所有牌开局可见，将四种花色分别从 A 收到 K，收完 52 张牌即获胜。

1. **红黑交替，点数递减。** 例如红色 6 可以放在黑色 7 上。
2. **中转格每格一张。** 可以暂存挡路的牌，为其他牌打开路线。
3. **空列可以放任意牌。** 腾空一列能让整理牌组更灵活。
4. **连续牌组可以一起搬。** 搬动上限取决于空中转格和空列数量：`(空中转格 + 1) × 2^可用空列数`，目的地为空列时不计入可用空列。
5. **收牌区可以取回顶牌。** 取回的牌暂不自动收起，需要时可手动移回。

点选牌后再点目的地，或直接拖动。移动端点击露出的单张牌会尝试收牌；偏好设置中还可以开启单击便捷移动。

支持提示、撤销、重做、安全自动收牌和一键完成。提示会解释建议，但不保证通关。

**长按“提示”3 秒**可验证当前局面是否有解。找到解法后，牌桌会快速演示并自动恢复原来的牌面；验证期间暂停计时并锁定操作，步数、撤销记录、成绩和经验均不改变。求解完全在本地进行，使用内置 Freecell Solver 与特殊规则搜索；计算达到上限时提示“暂未确认”，只有确认后才提示无解。

### 四档难度与编号牌局

| 难度 | 特点 | 每日首局基础经验 |
| --- | --- | ---: |
| 简单 | 开局可安全收起至少两张牌，所有 A 上方最多三张牌 | 100 XP |
| 中等 | 至少一张 A 上方最多一张牌，所有 A 上方最多四张牌 | 250 XP |
| 困难 | 关键牌较深，更需要规划空间 | 500 XP |
| 专家 | 关键牌深埋，考验整理顺序 | 1000 XP |

四档难度各自按当天完成局数递增基础经验：每通关一局，该难度下一局增加一份基础经验。例如专家当天各局依次为 **1000、2000、3000、4000、5000 XP……**，北京时间次日重置。重新开始同一编号也按新一局结算，同一局只结算一次；每日挑战不参与此递增。首胜与速度加成按本局递增后的基础经验计算，成就奖励单独叠加。难度入口显示下一局奖励，包含可用的首胜加成。

支持 **1–9,999,999** 微软兼容编号牌局。同一编号始终对应同一牌面，可以指定编号重玩，也可以按编号顺序推进。

难度根据开局结构估算，并非最短解或实际难度的证明。简单、中等还限制所有 A 的总埋藏深度及低点数牌的埋藏分数；只有列尾连续、可移动的牌组能降低这两档的分数，藏在列中间的组合不计入优惠。随机难度选局、顺序选局会跳过清单中的 130 个已知无解编号；手动指定这些编号仍可查看原始牌面。

## 每日挑战

每日玩法放在“新牌局”下面，选择后直接进入牌桌，规则和目标显示在工具栏上方。**每天按北京时间零点换题，当天重玩保持相同牌面。**

| 玩法 | 如何完成 | 每日基础奖励 |
| --- | --- | ---: |
| 每日大师挑战 | 标准 52 张对局，筛选比专家档结构更复杂的牌面 | 5000 XP |
| 每日残局挑战 | 在收官、中转解围、腾空行动中轮换目标 | 3000 XP |
| 每日特殊规则 | 每天轮换封印一格、王者空列或花色优先 | 3000 XP |
| 每日精准挑战 | 按目标步数完成残局，争取金、银、铜牌 | 3000 XP |
| 每日同花挑战 | 同花色递减叠牌，收牌区从 A 到 K | 3000 XP |
| 每日逆序挑战 | 红黑交替递增叠牌，收牌区从 K 到 A | 3000 XP |

### 每日残局挑战

新版残局保留 44–48 张牌，开局三个中转格被占用，八列均有牌。关键收牌深埋，牌列交叉阻挡，优先选择无法仅靠自动收牌完成目标的布局。轮换三种目标：

- **收官残局：** 将剩余牌全部收起。
- **中转解围：** 收起至少 40 或 44 张牌（剩余牌的 90%，向上取整），再清空四个中转格。
- **腾空行动：** 收起至少 40 或 44 张牌，再腾空指定牌列。

当前目标和进度会显示在牌桌上。残局同样支持提示、撤销和安全自动收牌。

### 每日特殊规则

- **封印一格：** 第四个中转格不可用，搬牌容量也只计算其他三个格。
- **王者空列：** 空列只能接 K 或以 K 开头的牌组；空列不增加搬牌容量。
- **花色优先：** 指定花色必须先收到 K，才能收其他花色。取回优先花色的顶牌会重新锁定其他收牌区。

### 每日精准挑战

A、2 已经收起，从剩余 44 张牌开始，开局中转空间受限，需要先拆解交叉阻挡。当天牌面有自己的金牌目标；超出银牌目标仍可通关，获得铜牌。

- 搬动一张牌或一整组牌算一步。
- 收起每张牌算一步，自动与手动收牌采用相同计分。
- 撤销退回该次操作的步数，重做恢复。
- 通关展示奖牌和个人最佳，可重玩尝试更少步数。

每天首次通关统一获得 **3000 XP** 基础奖励，金、银、铜牌不影响经验，重玩可刷新成绩。入口显示当日可领经验，含可用的今日首胜加成，领取后显示“已领取”。金牌目标依据生成时保留的可解路线设置，不代表经过证明的最少步数。

### 每日同花与逆序挑战

**同花挑战**只接受同花色递减叠牌，例如 ♠6 接在 ♠7 上；中转格、空列和 A→K 收牌照常使用。

**逆序挑战**将整理方向翻转：红色 7 接在黑色 6 上，收牌从 K→Q→J 一直收到 A。中转格和空列照常使用。

每日大师从经典编号牌局中确定性筛选；残局、特殊规则、精准、同花和逆序牌面以日期为种子，从完成状态倒推构造，保留合法通关路线。同一版本、同一日期会生成相同牌面，无需联网下载每日题目。

新版特殊规则、同花与逆序挑战会预占部分可用中转格，并加强关键牌埋藏与交叉阻挡。旧存档与旧记录重玩仍使用原版布局；不同版本不混算最佳成绩，每种玩法的同日经验仍只领取一次。

## 等级、成就与记录

- **经验与等级：** 通关积累经验，解锁等级称号和徽章。
- **今日首胜：** 所有玩法共用一次首胜翻倍，额外奖励等于对应基础经验。
- **每日奖励：** 每种每日玩法每天结算一次，领取后入口显示“已领取”。跨天完成保存的旧残局或特殊玩法只记录成绩。
- **速度奖励：** 经典牌局和当日大师挑战可获得限时通关奖励，满足条件后在胜利结算中展示。
- **50 项成就：** 覆盖速度、空间管理、操作技巧、专家连胜、个人突破与每日挑战，包括精准挑战的“五日金牌”。成就经验独立结算，每项领取一次。
- **成绩记录：** 保存最近 100 局、经典编号最佳步数与用时，以及各每日玩法的独立最佳成绩。

每日大师计入经典胜率、连胜和编号成绩；其他每日玩法独立记录，不影响经典连胜或经典技巧成就。

## 牌桌与操作体验

原创人物牌面与徽章，提供绿绒、午夜蓝、酒红绒主题，也可以选本地照片作为背景。支持横竖屏、中转格位置调整、加大点数、游戏音效和可选轻震。

发牌、搬牌、撤销与收牌带有动画；牌面使用 PixiJS 缓存渲染。应用自动保存当前牌局和撤销历史，重新打开可以继续。

数据保存在当前设备的 localStorage 中，无账号或云同步。浏览器与原生应用的存档互相独立，卸载或清理应用数据会删除记录。

## 本地运行

技术栈：**React 19 · TypeScript · Vite · PixiJS 8 · Tauri 2**。

### 浏览器

准备 Node.js 和 pnpm，使用项目 `package.json` 中指定的 pnpm 版本：

```sh
pnpm install
pnpm dev
```

打开 `http://localhost:1420`。浏览器开发无需编译 Rust。

### 桌面与手机

原生开发需要 Rust 和对应平台工具链。iOS 使用 macOS、Xcode 和自己的 Apple 开发签名；Android 使用 JDK、Android SDK 与 NDK。项目保留了 iOS、Android 原生工程。

```sh
# 桌面窗口
pnpm tauri dev

# iOS 模拟器或真机
pnpm ios:dev

# Android 模拟器或真机
pnpm android:dev
```

iOS 请将 `src-tauri/tauri.ios.conf.json` 与 Xcode 的 Signing & Capabilities 改为自己的开发团队。真机开发时，手机和电脑应处于相同局域网。已有原生工程包含定制代码，通常无需重新初始化。

```sh
# 前端构建
pnpm build

# iOS 安装包，需要 Apple 签名
pnpm ios:build

# Android APK
pnpm android:build --apk

# 根据 app-icon.svg 更新各平台图标
pnpm icons
```
