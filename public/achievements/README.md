# 成就插画设计稿

50 项当前成就使用原创 SVG 插画。旧日历的 4 项成就已停用，保留历史资源；新增 8 项大师与残局成就，沿用玩法珐琅徽章图案。
按长期积累、速度、空间管理、整理与操作、解局能力、专家与连胜、自我突破、每日挑战分八类。
采用圆角珐琅铭牌，主体插画不复用等级徽章，也不依赖外部图标或字体。
生成器同步输出 manifest.json 和 src/achievementCatalogue.json，判定逻辑位于 src/achievements.ts。
旧版插画生成器：scripts/create-achievement-art.py（仅用于历史设计稿，当前新增每日玩法资源和目录手动维护）。

特殊规则新增三项成就：首次通关、完成十个不同日期、三种规则全部通关。

精准、同花、逆序分别新增首次完成与十日通关成就；精准另有五日金牌。
