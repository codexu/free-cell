# 原创珐琅徽章

本项目自行绘制的 SVG 插画，共 25 个等级徽章、4 个月度挑战徽章及 7 个玩法入口徽章。
全部主体路径为本项目原创；没有下载、切割或描摹付费素材，也不依赖第三方图标。
珐琅底色构成统一视觉语言；等级边框依次为素铜、刻银、桂冠金、冠饰铂金及宝石宗师框。五枚宗师徽章另有翼饰、日芒、月环、王庭及钻石切面轮廓，等级主体各不相同。
SVG 使用内部渐变、固定颜色，无字体、外部资源、滤镜或动画。

玩法入口徽章使用 `gameplay-` 前缀：简单为铜框单牌，中等为银框双牌，困难为金框城堡，专家为铂金框王冠双剑；每日大师为紫晶框日轮王牌，每日残局为金框青绿拼图王牌。入口图标不是已获取的成就，不受成就解锁状态影响。

每日特殊规则使用 `gameplay-daily-special.svg`：金色齿轮外环、暖棕珐琅与居中王牌，代表每日轮换的游戏规则。
